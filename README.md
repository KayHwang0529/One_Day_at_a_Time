To run this game, please first clone this github repo that contains all the files, art, and plugins needed to compile it. 
(link to my project) https://github.com/KayHwang0529/One_Day_at_a_Time 
You should then be sure to download godot on your local device as the editor is the key to running the game.
Then launch the Godot application, which should open up the project manager as the first window. 
In the Godot Project Manager, choose “Import” (if the project isn’t listed) or “Open” (if the project folder is present).
If you just imported the project, Godot will scan for project files (project.godot etc) and load them.
Ensure that your plugins appear under the Plugins/Addons section and are enabled.
  The plugins should be stored in the project under addons/(e.g. addons/pandora/, addons/dialogue_manager/, addons/quest_system/)
  Once you open the project in the Godot editor, enable each plugin via Project → Project Settings → Plugins (just in case they aren't already)
Also make sure that all files are res:// folder in the bottom left side of the Godot editor, if not you might need to reroute necessary files to run the game. 
In the Project Settings → “Application” (or Editor → Project Settings, depending on engine version), make sure the Main Scene ("Game") is set.
Press “Play” (the triangle in the upper right corner) in the Godot editor — this will launch the game.
Following the Quest box at the top, play through the game walking through each step. Also occasionally open the inventory with the "Q" bar on your keyboard to check your status (ensuring quest completion)
Once the game has concluded (3 quests are completed) walking to the bed should result in the end screen popping up (signaling the end of the game). From that point, closing the window and reclicking the triangle,
will allow you to replay the game! Have fun, and I hope you learn a lot!
